# Plant Organizer — органайзер домашних растений

Android-приложение для ухода за комнатными растениями (вариант 7).
Kotlin · Jetpack Compose · Material 3 · MVVM + UDF · Hilt · Room · Realm · Retrofit · CameraX + ML Kit · WorkManager.

## Что умеет приложение

| Функция | Описание |
|---|---|
| Календарь полива | Главный экран: список растений. Карточка меняет цвет, если полив просрочен или скоро нужен. Кнопка «Полить» записывает полив. |
| Карточка растения | Условия содержания (свет, влажность, температура), справка из API и журнал ухода (поливы, подкормки, пересадки). |
| Сканер этикетки | Камера читает название цветка с этикетки или ценника (ML Kit). |
| Справка по уходу | Название отправляется в REST API Trefle (Retrofit), регламент ухода сохраняется в базу. |
| Напоминания | WorkManager присылает уведомление, когда пора поливать. |
| Справочник | Семейства растений и типы удобрений (Realm). |
| **Диагностика растения (LLM)** | Описываешь симптомы, LLM называет причину и советует, что делать. Ответы сохраняются в базе. |
| **Голосовой ввод ухода** | Говоришь «полил кактус» — приложение записывает уход в журнал и голосом называет дату следующего полива. |

Скриншоты лежат в папке `screenshots/`.

## Диагностика растения (лаба 5)

На экране растения нажми **«Диагностика»**, опиши симптомы (или выбери готовый вариант) и нажми **«Определить причину»**.
Ответ приходит в формате: причина (1 предложение) + рекомендация (1–2 предложения).

Как это устроено:

```
DiagnosisScreen ──▶ DiagnosisViewModel ──▶ DiagnosePlantUseCase ──▶ LlmRepository (интерфейс)
   (Compose)         StateFlow: Idle /        промпт, кэш,                  │
                     Loading / Success /      постобработка                 ▼
                     Error                         │                LlmRepositoryImpl ──▶ Gemini API (Retrofit)
                                                   ▼
                                           DiagnosisDao (Room) — кэш ответов
```

- **LLM:** облачный API Gemini. Ничего скачивать на телефон не нужно, ключ бесплатный.
- **Кэш:** каждый ответ сохраняется в Room. Повторный вопрос с теми же симптомами отвечает из базы, без интернета.
- **Нет интернета или лимит:** показывается понятное сообщение, а если есть старый ответ — он выводится вместо ошибки.

### Как получить бесплатный ключ

1. Открой <https://aistudio.google.com/apikey> и войди в Google-аккаунт.
2. Нажми **Create API key** (банковская карта не нужна).
3. Добавь в файл `local.properties` в корне проекта (в git он не попадает):

```properties
TREFLE_TOKEN=твой_токен_trefle
LLM_API_KEY=твой_ключ_gemini
# необязательно: название модели, если стандартная перестанет работать
LLM_MODEL=gemini-flash-latest
```

4. Синхронизируй Gradle и запусти приложение.

> Название модели можно посмотреть в Google AI Studio. Если приложение пишет «Модель не найдена», поменяй `LLM_MODEL`.

## Голосовой интерфейс (лаба 6)

На главном экране нажми **«Голос»**, затем кнопку с микрофоном и скажи, что сделал:

- «Полил кактус»
- «Подкормил розу»
- «Пересадил фикус»

Приложение найдёт растение, запишет событие в журнал ухода и **озвучит дату следующего полива**
(«Записал: полив, Кактус. Следующий полив — 15 ноября.»). Если не поняло фразу, подскажет, что сказать.

Как это устроено:

```
VoiceScreen ──▶ VoiceViewModel ──▶ VoiceRepository (интерфейс)
 (кнопка 🎤)     │  onCleared() →        │
                 │  release()            ▼
                 │             VoiceRepositoryImpl
                 │               ├─ SpeechRecognizer  (речь → текст)
                 │               └─ TextToSpeech      (текст → речь)
                 ▼
        RecordCareByVoiceUseCase ──▶ VoiceCommandParser (ищет действие и растение)
                 └──▶ PlantRepository (запись в журнал, Room)
```

- **Состояния** `VoiceUiState`: `Idle`, `Listening`, `Processing`, `Error` (через `StateFlow`).
- **Изоляция от UI:** `SpeechRecognizer` и `TextToSpeech` вызываются только в `VoiceRepositoryImpl`. Composable лишь просит разрешение на микрофон и сообщает ViewModel о нажатии.
- **Ресурсы:** `VoiceRepositoryImpl` живёт столько же, сколько `VoiceViewModel`; в `onCleared()` вызывается `destroy()` у распознавателя и `shutdown()` у синтезатора.
- **Ошибки обрабатываются:** нет разрешения на микрофон, микрофон занят, нет службы распознавания, язык не поддерживается, русский голос не установлен, ничего не расслышал.

> Для распознавания нужны сервисы Google и обычно интернет. Для озвучки на телефоне должен быть установлен русский голос.
